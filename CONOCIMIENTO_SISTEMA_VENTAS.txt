# ESTRUCTURA DE PROYECTO

### Resumen de Arquitectura
El proyecto es una aplicación web moderna (SPA) construida con **React 18** y **TypeScript**, utilizando **Vite** como herramienta de construcción. La interfaz se basa en **Tailwind CSS** con una estética premium, modo oscuro y diseño responsive adaptado a dispositivos móviles (PWA).

**Stack Tecnológico:**
- **Frontend:** React, TypeScript, Tailwind CSS, Lucide React (iconos), Recharts (gráficas).
- **Backend (BaaS):** Supabase (PostgreSQL, Auth, Storage).
- **IA:** Google Generative AI (Modelos Gemini 2.0/1.5 Flash) para análisis de tickets.
- **Automatización/Persistencia:** Google Apps Script (Sincronización con Drive y Sheets).
- **Utilidades:** html2canvas y jspdf para generación de reportes.

### Organización de Carpetas (Flat Structure)
El proyecto sigue una estructura simplificada donde el núcleo reside en la raíz y subcarpetas específicas:
- `/`: Contiene `App.tsx` (lógica central), `types.ts` (modelos), `constants.ts` y archivos de configuración.
- `/components`: Componentes modulares de la interfaz (Dashboard, SalesForm, AdminPanel, etc.).
- `/services`: Clientes de API y servicios externos (Supabase, Gemini, Google Script).
- `/public`: Activos estáticos y manifiesto PWA.

# INTEGRACIONES EXTERNAS

### 1. Supabase (Backend Principal)
- **Database:** Tablas para `sales`, `daily_closings`, `profiles`, `attendance`, `warranties` y `stores`.
- **Auth:** Manejo de sesiones y perfiles con triggers en PostgreSQL para creación de perfiles automáticos.
- **Storage:** Bucket `receipts` para almacenamiento inmediato de imágenes de tickets y evidencias de asistencia.

### 2. Gemini AI (Análisis de Tickets)
Servicio ubicado en `geminiService.ts`. Utiliza modelos Flash para:
- Extraer `invoiceNumber`, `date`, `customerName` e `items` (dispositivos) desde fotos.
- Filtrar automáticamente elementos no deseados (seguros, chips, fundas).
- Normalizar nombres de marcas y fechas.

### 3. Google Apps Script (Drive & Sheets)
Sincronización híbrida gestionada en `googleAppsScriptService.ts` y `storageService.ts`:
- **Drive Mirroring:** Cuando se sube una imagen a Supabase, se envía una copia en segundo plano a Google Drive para respaldo administrativo.
- **Market Participation:** Sincroniza cierres diarios (ventas Telcel vs AT&T) con hojas de cálculo para reportes corporativos.
- **Email Invites:** Envío de correos de invitación a nuevos usuarios con enlaces de registro parametrizados.

### 4. Flujo de Imagen Inteligente (`smartImageUpload`)
1. Sube a **Supabase Storage** para disponibilidad inmediata en la app.
2. Dispara un proceso `fire-and-forget` hacia **Google Drive** vía Apps Script.
3. Organiza jerárquicamente en Drive: `Tienda / Año / Mes / Día / Archivo.jpg`.
